## 🧭 ¿Cuándo consultar esta carpeta?
- **Antes del Hackathon:** Los organizadores y mentores leen la `guia_pedagogica` y el `marco_teorico` para alinear la narrativa y resolver dudas.
- **Durante el Hackathon:** Los participantes consultan el `glosario_tecnico` y los detalles de los `datos_eic_nasa` para enriquecer la explicación de su proyecto.
- **Al Cierre:** El jurado utiliza la `rubrica_evaluacion_jurado` para calificar de manera transparente y constructiva.
